Häufige Fragen

Der Code lässt sich an der Kasse nicht scannen. Was kann ich tun?

Schalte in den Einstellungen „Helligkeit erhöhen“ ein: Der Bildschirm wird hell und bleibt an, solange eine Karte offen ist. Bei einem langen Code hilft „Gedreht zeigen“. Hast du den Code aus der App eines Händlers übernommen, kann er sich dort ändern. Am sichersten speicherst du die Nummer der Plastikkarte.

Wie füge ich eine Karte ohne Kamera hinzu?

Tippe auf „Karte hinzufügen“. Wähle dann „Aus Bildern importieren“, um Screenshots auszuwählen, oder „Nummer eingeben“, um Nummer und Format von Hand einzutragen.

Welche Codeformate funktionieren?

EAN-13, EAN-8, UPC-E, Code 128, Code 39, ITF, Codabar, QR, Aztec und PDF417. Die App speichert Nummer und Format genau so, wie sie gelesen wurden.

Was passiert mit meinen Karten auf einem neuen iPhone?

Die Karten liegen auf dem iPhone, auf dem du sie gespeichert hast. Der Abgleich über deine eigene iCloud ist in den Testversionen noch aus. Ein neues iPhone beginnt deshalb ohne Karten.

Wie lösche ich eine Karte?

Wische in der Kartenliste die Zeile nach links und tippe auf „Löschen“. Die App fragt vorher nach.

Schickt die App meine Kartennummern irgendwohin?

Nein. Die App zeichnet Barcodes auf dem Gerät. Eine Kartennummer geht nur in deine eigene iCloud und an keinen anderen Dienst.
