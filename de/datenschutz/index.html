Datenschutz

Keine Daten

Die App sammelt keine Daten über dich. Es gibt kein Konto, keine Analyse, keine Werbung und keine Software von Dritten.

Deine Karten

Deine Karten liegen auf diesem iPhone. Wenn du iCloud nutzt, liegen sie auch in deiner privaten iCloud-Datenbank. Nur du hast darauf Zugriff, der Herausgeber nicht.

Barcodes

Die App zeichnet Barcodes auf dem Gerät. Eine Kartennummer geht nur in deine eigene iCloud und an keinen anderen Dienst.

Netz

Die App verbindet sich nur mit iCloud, um Karten abzugleichen, und mit dem App Store, um den einmaligen Kauf abzuwickeln.

Diese Website

Diese Website liegt bei GitHub Pages (GitHub, Inc., USA). Wenn du eine Seite aufrufst, speichert GitHub deine IP-Adresse zur Sicherheit. Das gilt auch, wenn du nicht bei GitHub angemeldet bist. Wie lange GitHub sie speichert, legt GitHub fest.

Diese Website setzt keine Cookies. Sie hat keine Analyse, kein Tracking, keine Schriften und keine Inhalte von anderen Servern und kein Kontaktformular.

Rechtsgrundlage ist das berechtigte Interesse des Herausgebers, die Seite sicher und erreichbar bereitzustellen (Art. 6 Abs. 1 Buchst. f DSGVO). Die IP-Adresse ist technisch nötig, damit die Seite bei dir ankommt. GitHub stützt die Übermittlung in die USA auf die Standardvertragsklauseln der EU-Kommission und das EU-US Data Privacy Framework. Es gibt keine automatisierte Entscheidung und kein Profiling.

Der App Store und TestFlight sind Dienste von Apple. Apple verarbeitet Daten zu Downloads und Tests nach der eigenen Datenschutzerklärung von Apple.
